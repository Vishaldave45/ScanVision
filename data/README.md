# Data Directory
 
This directory contains local datasets and generated image artifacts for ScanVision.
 
## Structure
 
- `raw/`: Raw input images used for testing and experimentation.
- `processed/`: Intermediate and final image artifacts output by the pipeline.
 
## Data Governance
 
- Generated images in `processed/` are intentionally git-ignored.
- Do not commit sensitive, confidential, or personally identifiable documents to the repository.
